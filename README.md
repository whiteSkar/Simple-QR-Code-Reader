# Simple QR Code Reader

Simple QR Code Reader is a Chrome extension for reading QR codes that are visible on the current web page.

When invoked, it scans the visible area of the active tab and marks detected QR codes on the page so you can choose which one to copy. If no QR code is detected, it shows a short message.

The extension runs locally in the browser and is intended for quickly extracting URLs or text from QR codes without using a phone camera.
